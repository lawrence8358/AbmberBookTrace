# 書蹤水彩素材

依 `需求書/視覺設計稿.png` 的水彩、奶油白、鼠尾草綠及珊瑚色製作；使用內建 image_gen。素材是重新生成的插畫，並非從設計稿直接裁下。

| 素材 | 原始透明 PNG | 網頁用 WebP | 接入位置 |
| --- | --- | --- | --- |
| 貓咪、書堆與植物 | `reading-cat.png`，1536 × 1024 | `../../../src/booktrace-client/public/images/reading-cat.webp`，768 × 512 | 書庫迎賓及共用功能頁標題 |
| 閱讀女孩、書與茶杯 | `reading-girl.png`，1536 × 1024 | `../../../src/booktrace-client/public/images/reading-girl.webp`，768 × 512 | 桌面側欄、各頁空狀態、頂部頭像 |

兩張都有真正的透明 alpha，可放在奶油白或其他淺色背景。保留完整比例，不裁切角色；背景文字由 HTML 呈現，不燒進圖檔。插畫使用空 alt，避免裝飾被螢幕閱讀器重複朗讀。

完整生成提示存於 [prompts.md](prompts.md)。PNG 內亦保留生成提示；WebP 旁的 JSON 是來源說明。網頁只載入 WebP，不需下載原始 PNG。

## 本次前端調整

- 品牌圖示改為珊瑚色，按鈕採較柔和但仍能辨識白字的綠色。
- 搜尋框、統計、書籍卡片收斂間距，手機統計改為橫向三欄。
- 最近新增補上真實封面；沒有封面時明確顯示「尚無封面」，不使用生成插畫假冒書封。
- 啟用搜尋或狀態篩選時隱藏最近新增，讓結果更容易找到。
- 保留既有路由、資料操作與全站單一中文字體。手寫品牌字樣與原稿的逐像素還原不在本次交付內。
- 依後續回饋移除側欄新增按鈕、上移選單、放大閱讀插畫；頂部補回頭像。
- 手機底部改為首頁、歷史、新增、提醒、回收筒五格；新增置中。
- 功能頁共用標題元件，詳情頁調整封面／資料分欄，卡片、空狀態與表單風格一致。
