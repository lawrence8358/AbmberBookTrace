# 問題分類標籤

其他工程技能會使用五種固定的問題分類。下面是它們在這個專案中使用的標籤名稱。

| 固定分類 | 這個專案使用的標籤 | 意思 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 還需要有人先看看這個問題 |
| `needs-info` | `needs-info` | 正在等提問的人補充資料 |
| `ready-for-agent` | `ready-for-agent` | 資料已經完整，可以交給代理人處理 |
| `ready-for-human` | `ready-for-human` | 需要人類親自處理 |
| `wontfix` | `wontfix` | 這個問題暫時不會處理 |

如果其他技能提到某個分類，就使用表格右邊的標籤名稱。

如果之後專案改用別的標籤名稱，只要修改表格右邊那一欄即可。
