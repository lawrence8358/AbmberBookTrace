# 「書蹤」個人藏書管理網站 MVP 企劃書

## 1. 專案名稱

**書蹤**

副標題：

> 找到我的每一本書。

---

## 2. 專案背景

喜歡看書的人，書越來越多之後，很容易遇到這些問題：

- 明明記得自己有這本書，卻不知道放在哪裡。
- 書可能放在房間書櫃、書桌、收納箱或其他地方。
- 有些書借給同學後，過一段時間忘記是誰借走。
- 想買一本書時，不確定自己是不是已經有了。
- 書越來越多後，只靠記憶很難管理。

因此希望製作一個簡單的個人藏書管理網站「書蹤」，讓使用者可以快速確認：

1. 我有沒有這本書？
2. 這本書現在放在哪裡？
3. 如果不在我這裡，是不是借給別人了？

---

## 3. 第一階段目標

第一版先以**個人使用**為主，不急著加入帳號、密碼、社群或多人共享功能。

第一版最重要的是把以下流程做好：

1. 新增一本書
2. 搜尋一本書
3. 查看書放在哪裡
4. 記錄書借給誰
5. 書還回來後改回「在家」

網站需要同時支援：

- PC 電腦
- 手機

採用響應式網頁設計，同一個網站可以依螢幕大小自動調整版面。

---

## 4. 第一版是否需要「分類」？

### 建議：保留，但不要把分類做得太複雜

第一版的核心目標是：

> 找得到書，而不是整理出一套很完整的圖書分類制度。

因此第一版**不建議**製作：

- 多層分類
- 分類管理頁
- 主分類 / 次分類
- 自訂分類樹
- 一本書同時掛很多分類
- 強制每本書一定要選分類

這些功能很容易讓網站變複雜，但對第一版「找書」的幫助有限。

### 第一版建議做法

書籍資料保留一個：

**分類 / 標籤（選填）**

例如：

- 小說
- 漫畫
- 科普
- 歷史
- 推理
- 散文
- 課外讀物

新增書籍時可以填，也可以完全不填。

未來如果真的發現書很多，常常想用分類找書，再把分類功能加強。

### 結論

第一版：

> **分類不是必要功能，但建議保留一個簡單、選填的欄位。**

這樣不會增加太多開發難度，也替未來留下擴充空間。

## 5. 第一版 MVP 功能範圍

### 5.1 首頁

首頁提供：

- 搜尋框
- 我的藏書總數
- 借出中的書籍數量
- 最近新增的書
- 新增書籍按鈕

首頁最重要的功能是：

> 打開「書蹤」後，可以立刻搜尋。

---

## 5.2 搜尋書籍

可依以下內容搜尋：

- 書名
- 作者
- ISBN
- 關鍵字

搜尋結果至少顯示：

- 書名
- 作者
- 目前狀態
- 書籍位置

例如：

```text
小王子
作者：安東尼・聖修伯里

狀態：在家
位置：房間書櫃
詳細位置：第二層左邊
```

如果借出：

```text
小王子

狀態：借出中
借給：小美
借出日期：2026/09/15
```

---

## 5.3 新增書籍

PC 與手機都可以新增書籍。

### 必填欄位

- 書名

### 選填欄位

- 作者
- ISBN
- 出版社
- 分類 / 標籤
- 位置
- 詳細位置
- 備註

第一版應避免必填欄位太多，否則每新增一本書都會很麻煩。

---

## 5.4 書籍位置

因為「書蹤」最重要的目的就是找書，所以「位置」是第一版的重要欄位。

建議拆成兩個欄位：

### 位置

例如：

- 房間書櫃
- 客廳書櫃
- 書桌
- 收納箱
- 學校
- 其他

### 詳細位置

例如：

```text
位置：房間書櫃
詳細位置：第二層左邊
```

或：

```text
位置：收納箱
詳細位置：藍色收納箱 A
```

這樣以後書變多時，比只寫一大段文字更容易找。

---

## 5.5 借出與歸還

一本書可以有兩種主要狀態：

- 在家
- 借出中

當書借給同學時，可以記錄：

- 借給誰
- 借出日期
- 備註

例如：

```text
狀態：借出中
借給：小美
借出日期：2026/09/15
備註：下星期還
```

書還回來後，只要按：

**已歸還**

系統就把狀態改回：

**在家**

第一版不用做複雜的借閱系統，也不需要讓借書的同學登入。

---

## 5.6 我的書庫

可以查看所有書籍。

建議提供：

- 搜尋
- 全部
- 在家
- 借出中

如果之後分類真的有使用需求，再增加分類篩選。

例如：

| 書名 | 作者 | 位置 | 狀態 |
|---|---|---|---|
| 小王子 | 聖修伯里 | 房間書櫃 | 在家 |
| 哈利波特 | J.K. Rowling | — | 借出中 |
| 原子習慣 | James Clear | 書桌 | 在家 |

這些都可以等「書蹤」第一版實際使用後，再決定哪些功能真的需要。

## 10. 第二階段可考慮功能

### 10.1 掃描 ISBN

未來可以使用手機掃描書本背面的 ISBN 條碼，自動取得：

- 書名
- 作者
- 出版社
- 書籍封面

這會大幅加快新增書籍的速度。

### 10.2 書籍封面

書庫除了文字，也可以顯示封面，讓使用者更快認出書籍。

### 10.3 閱讀狀態

未來可以另外加入：

- 想讀
- 閱讀中
- 已讀完

但「閱讀狀態」與「書在哪裡」是兩件不同的事情。

建議分開：

```text
BookStatus
在家 / 借出
```

```text
ReadingStatus
想讀 / 閱讀中 / 已讀完
```

不要混成同一個欄位。

### 10.4 分類功能升級

如果未來藏書越來越多，而且確實常用分類找書，再考慮：

- 分類篩選
- 自訂分類
- 一書多標籤
- 熱門分類
- 分類統計

第一版不需要先做。

## 11. 未來多人使用

第一版先個人使用，不需要登入。

但資料設計可以預留：

```text
UserId
```

未來變成多人版時，可以改成：

```text
User
 └── Books
```

每個帳號只能看到自己的書。

到時再增加：

- 註冊
- 登入
- 密碼
- 忘記密碼
- 使用者權限

不需要第一版就把帳號系統做進去。

## 17. 書蹤的核心理念

「書蹤」不是大型圖書館系統。

第一版只需要回答三個問題：

> **我有這本書嗎？**

> **這本書在哪裡？**

> **如果不在我這裡，是誰借走了？**

只要這三件事情做好，「書蹤」第一版就已經是一個真正實用的個人藏書管理工具。

## 18. 視覺設計方向

以下視覺稿作為「書蹤」第一版的主要 UI / UX 設計參考。

![書蹤視覺設計稿](./視覺設計稿.png)

### 18.1 整體風格

「書蹤」的視覺風格以 **溫暖、清爽、帶有閱讀與手帳感** 為主。

整體特色：

- 大量使用奶油白、米白色背景，降低純白畫面的冰冷感。
- 主色使用柔和的綠色，讓畫面看起來自然、安靜。
- 搭配橘色作為「借出中」等需要提醒的狀態色。
- 書籍封面、紙張、植物與手寫文字，營造閱讀與收藏的氣氛。
- 卡片使用圓角與輕微陰影，不做過度複雜的立體效果。
- 整體介面不要像正式圖書館系統，而是比較像「自己的私人書房」。

### 18.2 主要色彩規劃

依照視覺稿，第一版可先使用以下色彩方向：

| 用途 | 建議色彩 |
|---|---|
| 主色 | 柔和綠 `#8CB69B` |
| 輔助暖色 | 珊瑚橘 `#F4A896` |
| 輔助藍色 | 淺藍 `#A7C7E2` |
| 背景色 | 奶油白 `#FFF9F1` |
| 主要文字 | 深灰 `#5B5B5B` |
| 在家狀態 | 綠色系 |
| 借出中狀態 | 橘黃色系 |
| 已歸還 / 次要狀態 | 灰色系 |

> 實際開發時，可以再依螢幕顯示效果微調明暗度與對比，並確保文字有足夠的可讀性。

### 18.3 電腦版畫面方向

電腦版以「快速查看整體藏書狀況」為主。

#### 左側導覽列

包含：

- 首頁
- 我的書庫
- 新增書籍
- 借閱記錄
- 分類
- 設定

第一版若暫時不強調分類，可以先保留入口，或先隱藏，等未來真的需要時再開放。

#### 頂部搜尋列

搜尋框固定在頁面上方明顯位置，可搜尋：

- 書名
- 作者
- ISBN

旁邊提供搜尋按鈕。

#### 首頁資訊卡

首頁可顯示三個主要數字：

- 我的藏書
- 在家
- 借出中

例如：

```text
我的藏書 128 本
在家 125 本
借出中 3 本
```

讓使用者一進入網站就能知道目前的藏書狀態。

#### 最近新增書籍

使用卡片方式呈現：

- 書籍封面
- 書名
- 作者
- 位置
- 狀態

狀態以小型圓角標籤呈現，例如：

```text
● 在家
```

或：

```text
● 借出中
```

### 18.4 書籍詳細頁

書籍詳細頁以「資訊清楚、快速管理」為主。

主要顯示：

- 書籍封面
- 書名
- 作者
- ISBN
- 分類
- 位置
- 詳細位置
- 狀態
- 借閱人
- 借出日期
- 備註

PC 版另外提供：

- 借出給同學
- 編輯資料
- 刪除

按鈕應依重要程度區分：

- 主要操作：綠色
- 編輯：白底 / 綠色外框
- 刪除：淡紅色 / 紅色文字

避免讓「刪除」按鈕太過突出，以降低誤按機會。

### 18.5 手機版畫面方向

手機版以「搜尋與快速查看」為主。

上方包含：

- Logo
- 通知或功能圖示
- 個人圖示

主要內容：

- 搜尋框
- 狀態篩選
- 書籍列表

狀態篩選可以使用：

```text
[全部] [在家] [借出中]
```

每本書以直向列表顯示：

```text
[封面] 書名
       作者
       位置
       狀態
```

手機版應避免一次顯示太多資料，只保留最重要的：

- 書名
- 作者
- 位置
- 狀態

需要更多資料時，再點進詳細頁查看。

### 18.6 手機版底部導覽

手機版可採用底部導覽列：

- 首頁
- 搜尋
- 新增
- 分類
- 我的

其中「搜尋」與「新增」應是最容易點到的位置。

如果第一版不做分類，可以把「分類」改成：

- 書庫

或直接簡化成四個項目。

### 18.7 UI 元件風格

#### 搜尋框

- 大圓角
- 淺灰或米白背景
- 左側放搜尋圖示
- Placeholder：

```text
搜尋書名、作者、ISBN
```

#### 卡片

- 白色或奶油白
- 圓角
- 輕微陰影
- 卡片之間保留足夠間距

#### 狀態標籤

在家：

```text
● 在家
```

使用綠色系。

借出中：

```text
● 借出中
```

使用橘黃色系。

已歸還：

```text
● 已歸還
```

使用灰色系。

#### 按鈕

主要按鈕：

```text
搜尋
新增書籍

儲存
```

使用綠色背景。

危險操作：

```text

```

使用淡紅色或紅色外框。

### 18.8 插畫與裝飾元素

視覺稿中有：

- 書本
- 綠色植物
- 小貓
- 手寫便條紙
- 閱讀中的女孩
- 書桌與咖啡杯

這些元素可以用在：

- 首頁 Banner
- 空資料畫面
- 登入頁
- 關於書蹤
- 手機歡迎頁

但實際功能頁面不宜放太多插畫，避免干擾搜尋與管理書籍。

建議原則：

> 功能頁簡潔，品牌頁溫暖。

### 18.9 品牌文字風格

Logo「書蹤」可以保留略帶手寫感的中文字型。

一般操作介面則建議使用清楚、容易閱讀的繁體中文字型。

文案風格可以保持溫暖、自然，例如：

```text
午安，小書迷！
閱讀讓平凡的日子，也閃閃發光。
```

或：

```text
一本書，
是一個新的世界。
```

但功能按鈕仍應保持直接，例如：

```text
新增書籍
借出
已歸還
修改
刪除
```

不要為了文青感而讓操作文字變得難懂。

### 18.10 第一版視覺設計原則

第一版開發時應遵守：

1. **手機與 PC 使用相同品牌風格。**
2. **搜尋永遠是最明顯的功能之一。**
3. **「在家」與「借出中」要一眼就能分辨。**
4. **書籍位置資訊要比分類資訊更重要。**
5. **不要因為插畫漂亮而犧牲操作空間。**
6. **整體保持像自己的私人書房，而不是正式圖書管理系統。**

這份視覺稿將作為「書蹤」第一版 UI 設計的主要參考。
