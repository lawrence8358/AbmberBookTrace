# 書蹤 MVP 規格

## Problem Statement

個人藏書增加後，使用者很難只靠記憶回答三個問題：自己是否擁有某本書、書目前放在哪裡，以及書不在手上時是借給誰。書籍可能分散在不同房間、書櫃、桌面或收納箱，借出後也容易忘記借閱人與歸還期限。

目前沒有一個簡單、快速、適合手機與電腦使用的私人書庫工具，讓使用者能以書名、作者或 ISBN 找到書，記錄書籍位置，管理借出與歸還，並在書籍逾期時得到提醒。

## Solution

建立「書蹤」個人藏書管理網站，先以單一使用者的私人書庫為範圍，不加入帳號、多人共享或社群功能。

使用者可以新增書籍、選擇或拍攝一張封面照片、記錄位置與基本資料，透過書名、作者或 ISBN 搜尋書籍。書籍有「在家」與「借出中」兩種持有狀態；借出時記錄借閱人、借出日期、預計歸還日期與備註，預計歸還日期預設為借出日後兩週。歸還後保留借閱歷史，並將目前狀態改回「在家」。

網站提供首頁、我的書庫、書籍詳細資料、新增／修改書籍、借閱歷史、通知／提醒、資源回收筒等功能頁面。介面採響應式設計，手機優先支援搜尋、查看、新增、借出與歸還；電腦版另外提供修改與刪除入口。刪除的書籍先保留 30 天，期間可以還原，期滿後自動永久移除。

## User Stories

1. 作為個人藏書者，我想在不登入帳號的情況下使用自己的私人書庫，以便快速開始管理書籍。
2. 作為個人藏書者，我想在首頁看到藏書總數，以便快速了解目前擁有多少本書。
3. 作為個人藏書者，我想在首頁看到目前在家的書籍數量，以便知道手邊可取用的藏書量。
4. 作為個人藏書者，我想在首頁看到借出中的書籍數量，以便知道目前有多少書不在自己手上。
5. 作為個人藏書者，我想在首頁看到最近新增的書籍，以便快速確認最近登錄的內容。
6. 作為個人藏書者，我想從首頁直接搜尋書籍，以便不用先進入其他頁面。
7. 作為個人藏書者，我想新增一本書時只必填書名，以便快速完成登錄。
8. 作為個人藏書者，我想填寫作者，以便日後依作者找到書籍。
9. 作為個人藏書者，我想填寫 ISBN，以便用 ISBN 找到特定版本的書。
10. 作為個人藏書者，我想填寫出版社，以便保存書籍的基本資料。
11. 作為個人藏書者，我想填寫一個簡單的分類或標籤，以便在書籍資料中保留基本的主題資訊。
12. 作為個人藏書者，我想不填分類也能儲存書籍，以便分類不阻礙快速登錄。
13. 作為個人藏書者，我想填寫書籍所在位置，以便知道書位於哪個房間、書櫃或收納空間。
14. 作為個人藏書者，我想填寫詳細位置，以便記錄書櫃層數、左右位置或收納箱名稱。
15. 作為個人藏書者，我想在書籍上留下備註，以便記錄版本、來源或其他提醒。
16. 作為個人藏書者，我想從電腦選擇封面圖片上傳，以便讓書籍列表更容易辨識。
17. 作為個人藏書者，我想從手機相簿選擇封面圖片，以便使用現有照片建立書籍資料。
18. 作為個人藏書者，我想直接用手機相機拍攝封面，以便新增書籍時不必先離開網站拍照。
19. 作為個人藏書者，我想替換或移除封面圖片，以便修正錯誤或更新照片。
20. 作為個人藏書者，我想允許擁有多本相同書名或 ISBN 的書，以便完整記錄不同版本或不同實體副本。
21. 作為個人藏書者，我想搜尋書名，以便快速確認自己是否擁有某本書。
22. 作為個人藏書者，我想搜尋作者，以便找出某位作者的全部藏書。
23. 作為個人藏書者，我想搜尋 ISBN，以便精確找到特定書籍。
24. 作為個人藏書者，我想用部分文字搜尋，以便不必輸入完整書名或作者名稱。
25. 作為個人藏書者，我想搜尋時忽略前後空白與英文字母大小寫差異，以便降低輸入格式造成的搜尋失敗。
26. 作為個人藏書者，我想在沒有輸入搜尋文字時瀏覽全部書籍，以便把搜尋頁當作書庫入口使用。
27. 作為個人藏書者，我想在書庫中查看全部、在家與借出中的書籍，以便快速切換不同持有狀態。
28. 作為個人藏書者，我想在書籍列表直接看到書名、作者、位置與狀態，以便不用逐本打開詳細頁。
29. 作為個人藏書者，我想依作者在書庫中的藏書數量由多到少排序，以便先看到自己收藏較多的作者。
30. 作為個人藏書者，我想在作者藏書數量相同時依書名排序，以便列表順序穩定且容易查找。
31. 作為個人藏書者，我想讓沒有作者資料的書排在最後，以便有作者的書先依規則呈現。
32. 作為個人藏書者，我想打開書籍詳細頁查看完整資料，以便確認書籍的所有資訊。
33. 作為個人藏書者，我想在詳細頁看到目前狀態，以便立即知道書是在家或借出中。
34. 作為個人藏書者，我想在詳細頁看到目前位置，以便在家時能找到實體書。
35. 作為個人藏書者，我想在詳細頁看到目前借閱人與到期日，以便知道借出中的書目前由誰保管。
36. 作為個人藏書者，我想將在家中的書借給某人，以便記錄書籍離開書庫的狀態。
37. 作為個人藏書者，我想借出時必須填寫借閱人，以便每筆借閱都有可辨識的對象。
38. 作為個人藏書者，我想讓借出日期由系統自動記錄，以便避免手動輸入錯誤日期。
39. 作為個人藏書者，我想讓預計歸還日期預設為借出日後兩週，以便大多數借閱情境不用額外設定。
40. 作為個人藏書者，我想修改或清除預計歸還日期，以便處理不同的借閱期限。
41. 作為個人藏書者，我想在借出時填寫備註，以便記錄「下星期還」等補充資訊。
42. 作為個人藏書者，我想將借出中的書標記為已歸還，以便把書籍狀態恢復為在家。
43. 作為個人藏書者，我想歸還後仍保留該次借閱紀錄，以便回顧書籍曾經借給誰。
44. 作為個人藏書者，我想查看一本書的所有借閱歷史，以便了解它過去的流轉狀況。
45. 作為個人藏書者，我想在借閱歷史中看到借閱人、借出日期、預計歸還日期、實際歸還日期與備註，以便完整掌握每次借閱。
46. 作為個人藏書者，我想查看目前尚未歸還的借閱紀錄，以便找出仍在外的書籍。
47. 作為個人藏書者，我想看到到期日當天的網站內提醒，以便記得向借閱人確認歸還。
48. 作為個人藏書者，我想看到逾期借閱的網站內通知，以便優先處理超過預計歸還日期的書籍。
49. 作為個人藏書者，我想在首頁或通知頁看到提醒入口，以便不用逐本檢查借閱紀錄。
50. 作為個人藏書者，我想不依賴 Email 或手機推播也能收到提醒，以便在私人單機環境中使用完整的提醒功能。
51. 作為電腦使用者，我想在電腦版修改書籍資料，以便修正位置、作者、分類或備註。
52. 作為電腦使用者，我想在電腦版刪除書籍，以便移除不再收藏的書籍。
53. 作為手機使用者，我想在手機版新增、借出與歸還書籍，以便在書櫃旁直接完成管理。
54. 作為手機使用者，我想在手機版查看清楚的書名、作者、位置與狀態，以便快速找到書。
55. 作為手機使用者，我想在手機版看不到修改與刪除入口，以便降低誤觸風險。
56. 作為電腦使用者，我想在刪除書籍前看到確認提示，以便避免意外刪除。
57. 作為個人藏書者，我想讓刪除的書籍先進入資源回收筒，以便有機會挽回誤刪資料。
58. 作為個人藏書者，我想在 30 天內還原被刪除的書籍，以便恢復完整資料。
59. 作為個人藏書者，我想讓被刪除的書籍在回收期間不影響書庫搜尋、統計與排序，以便目前書庫數據保持正確。
60. 作為個人藏書者，我想讓超過 30 天的刪除資料自動永久移除，以便避免回收筒無限增長。
61. 作為個人藏書者，我想在空書庫時看到清楚的空狀態與新增入口，以便知道下一步該如何開始。
62. 作為個人藏書者，我想在搜尋沒有結果時看到清楚的提示，以便知道是沒有符合資料，而不是網站故障。
63. 作為個人藏書者，我想在手機與電腦上使用相同的書籍資料，以便不必維護兩套書庫。
64. 作為個人藏書者，我想讓手機與電腦共用相同的品牌視覺，以便整體使用體驗一致。
65. 作為個人藏書者，我想讓「在家」與「借出中」使用明顯不同的狀態色，以便一眼辨識書籍狀態。

## Implementation Decisions

- 第一版是單一使用者的私人書庫，不提供註冊、登入、多人共享、好友、公開書櫃或權限管理。
- 技術方案採用 Vue 3 響應式前端、ASP.NET Core Web API 後端、SQLite 資料庫與 EF Core 資料存取層。
- 書籍資料以 `Book` 為核心，至少支援書名、作者、ISBN、出版社、分類／標籤、位置、詳細位置、備註、封面圖片、建立時間與更新時間。
- 書籍持有狀態只有 `HOME`（在家）與 `BORROWED`（借出中）。新增書籍預設為 `HOME`。
- 書名是唯一必填欄位；作者、ISBN、出版社、分類／標籤、位置、詳細位置、封面與備註皆為選填。
- 允許書名或 ISBN 重複，不以書名或 ISBN 作為資料唯一鍵。
- 分類／標籤只保留單一選填文字欄位，不建立分類管理頁、不支援多層分類、不支援多標籤，也不提供分類篩選。
- 位置與詳細位置都是自由文字，系統不建立位置字典或位置管理功能。
- 每本書最多有一張封面圖片。PC 可選擇圖片檔，手機可從相簿選取或直接使用相機拍攝；圖片可以替換或移除。MVP 不串接 ISBN 書籍資料服務，也不自動取得外部封面。
- 封面圖片只接受常見圖片格式，並限制單檔大小為 5 MB；不做多圖相簿、圖片辨識或自動裁切。
- 搜尋採不分大小寫、忽略前後空白的部分符合，搜尋書名、作者與 ISBN。空白搜尋文字代表瀏覽全部未刪除書籍。
- 書庫提供全部、在家、借出中三種狀態篩選；篩選可與文字搜尋同時使用。
- 書庫列表依未刪除書籍中每位作者的藏書數量由多到少排序；數量相同時依書名升冪排序；作者空白的書排在最後。首頁的最近新增區塊固定依建立時間由新到舊顯示四本，不套用書庫作者排序。
- 借出操作只允許對 `HOME` 書籍執行，必須填寫借閱人；借出日期由後端記錄當天日期。
- 借出時建立一筆借閱紀錄，預計歸還日期預設為借出日後 14 天，使用者可以修改或清除；備註為選填。
- 歸還操作只允許對目前借出中的書籍執行，會將目前借閱紀錄填入實際歸還日期，並將書籍狀態改回 `HOME`。既有借閱紀錄保留，不建立複雜的借閱工作流程。
- 借閱歷史以每次借出／歸還為單位保存，至少包含書籍、借閱人、借出日期、預計歸還日期、實際歸還日期與備註。歷史紀錄只讀，不提供修改或刪除。
- 通知與提醒採網站內呈現，不寄送 Email、不做手機推播。到期日當天顯示提醒，超過到期日則顯示逾期通知；通知可在首頁摘要與通知頁查看。
- 功能頁面包含首頁、我的書庫、書籍詳細資料、新增／修改書籍、借閱歷史、通知／提醒、資源回收筒。分類與設定不建立獨立功能頁。
- 手機與電腦共用同一組後端能力與資料模型。手機介面隱藏修改與刪除操作，電腦介面提供修改與刪除入口；裝置差異是 UX 限制，不作為安全權限機制。
- 刪除書籍採軟刪除，書籍在資源回收筒保留 30 天；保留期間可還原，還原時恢復封面、書籍資料與借閱歷史。超過 30 天由系統自動永久刪除。
- 軟刪除書籍不參與一般搜尋、書庫列表、首頁統計、最近新增與作者數量排序。
- 所有新增、修改、借出、歸還、刪除、還原與封面操作都需要回傳清楚的成功或失敗結果，前端應顯示可理解的錯誤訊息。
- 書籍新增與修改至少驗證書名不可為空；借出時借閱人不可為空；圖片格式與大小需符合限制；不對 ISBN 強制做格式或校驗碼驗證。
- 視覺方向採奶油白背景、柔和綠主色、橘色借出狀態、圓角卡片與輕微陰影；功能優先於插畫，封面與裝飾不能壓縮搜尋、位置與狀態資訊的可讀性。

## Testing Decisions

- 主要測試 seam 是完整瀏覽器流程：讓測試工具像真實使用者一樣操作網站，透過公開頁面與按鈕驗證外部行為，而不是測試 Vue 元件內部實作或後端私有方法。
- 測試環境使用臨時 SQLite 資料庫，每個測試情境從明確的乾淨資料開始，避免測試彼此污染。
- 核心驗收流程至少包含：新增書籍、搜尋書籍、查看位置、借出、查看目前借閱資訊、查看借閱歷史、收到到期／逾期提醒、歸還並確認狀態回到在家。
- 封面流程測試至少包含：PC 選擇圖片、手機選取或拍照、圖片顯示、替換圖片、移除圖片，以及不合格格式或超過大小時的錯誤提示。
- 書庫測試應驗證文字搜尋、全部／在家／借出中篩選、作者數量降冪排序、同數量時的書名排序、無作者書籍排序，以及空結果狀態。
- 借閱測試應驗證借閱人必填、借出日期自動建立、預計歸還日期預設為 14 天、修改或清除期限、歸還後歷史紀錄保留，以及錯誤狀態轉換被拒絕。
- 軟刪除測試應驗證刪除確認、書籍從一般書庫消失、30 天內可還原、還原後資料完整，以及超過 30 天自動永久移除。
- 響應式測試應在手機與電腦尺寸驗證搜尋、查看、新增、借出與歸還都可完成，並確認手機隱藏修改／刪除入口、電腦顯示修改／刪除入口。
- 統計測試應驗證總數、在家數、借出數會隨新增、借出、歸還、刪除與還原正確更新。
- 測試只檢查使用者可觀察的結果、資料狀態與錯誤訊息；不把元件名稱、資料庫實作細節或內部函式呼叫方式當成測試契約。

## Out of Scope

- 帳號註冊、登入、密碼、忘記密碼、使用者權限與多人共享。
- 社群、好友、公開書櫃、分享、留言、按讚與閱讀排行榜。
- ISBN 掃描、ISBN 外部查詢、書名／作者／出版社自動帶入與外部書籍 API。
- 多張封面照片、書籍相簿、圖片辨識、OCR、自動裁切與圖片內容分析。
- 想讀、閱讀中、已讀完等閱讀狀態；持有狀態與閱讀狀態不在本 MVP 混合。
- 多層分類、自訂分類樹、一書多分類、分類管理、分類統計與分類篩選。
- 借閱歷史的編輯、刪除、借閱人帳號與借閱人登入。
- Email、簡訊、手機推播、行事曆整合與外部通知服務。
- 回收筒中的手動永久刪除、刪除歷程與資料復原到任意時間點。
- 匯入／匯出、備份還原、跨裝置同步服務與雲端儲存管理。
- 獨立手機 App；手機與 PC 共用響應式網站。
- 分類、設定、通知偏好與個人帳號頁面等未列入功能頁面的管理功能。

## Further Notes

- 本規格以需求書、視覺設計稿與訪談決策為準；目前專案尚未有既有程式碼、背景詞彙文件或 ADR，因此本功能視為綠地建置。
- 「手機不能修改／刪除」是介面設計規則，不是權限或安全邊界。若未來加入公開部署、多人使用或權限要求，必須另立規格重新設計授權模型。
