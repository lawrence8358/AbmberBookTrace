# 02: 書庫搜尋、篩選、排序與首頁統計

**What to build:** 讓使用者能從首頁或我的書庫快速找到書，並透過持有狀態、作者藏書數量與書名排序理解整個私人書庫。首頁同時提供藏書統計與最近新增書籍。

**Blocked by:** 01: 建立書籍核心流程

**Status:** resolved

**Labels:** ready-for-agent

- [x] 使用者可以依書名、作者或 ISBN 進行不分大小寫、忽略前後空白的部分符合搜尋。
- [x] 空白搜尋可以瀏覽全部書籍，且搜尋沒有結果時顯示清楚的空狀態。
- [x] 使用者可以切換「全部」、「在家」與「借出中」三種狀態篩選。
- [x] 書庫依未刪除書籍中作者的藏書數量由多到少排序；數量相同時依書名排序；沒有作者的書排在最後。
- [x] 首頁顯示藏書總數、在家數量、借出中數量與最近新增的四本書。
- [x] 搜尋與狀態篩選可以同時使用，統計數字不因列表切換而顯示錯誤。
- [x] 有瀏覽器流程測試驗證搜尋、篩選、排序、首頁統計與最近新增書籍。

## Answer

- 新增 `/api/books` 的搜尋、狀態篩選與作者藏書數排序，並新增 `/api/books/stats` 回傳統計與最近四本書。
- 書庫頁加入即時搜尋、全部／在家／借出中篩選、統計卡、最近新增區塊與搜尋空結果提示。
- 瀏覽器流程測試涵蓋書名／作者／ISBN 搜尋、大小寫與前後空白、狀態篩選、組合篩選、排序、統計、最近新增與空結果。
