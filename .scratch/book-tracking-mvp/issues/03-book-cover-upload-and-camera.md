# 03: 書籍封面上傳與手機拍照

**What to build:** 讓使用者在新增或修改書籍時加入一張封面圖片。電腦使用者可以選擇檔案，手機使用者可以從相簿選擇或直接拍照，並能在書籍列表與詳細資料中看到封面。

**Blocked by:** 01: 建立書籍核心流程

**Status:** resolved

**Labels:** ready-for-agent

- [x] 使用者可以在電腦選擇圖片檔作為書籍封面。
- [x] 使用者可以在手機從相簿選擇圖片，或直接使用手機相機拍攝封面。
- [x] 每本書最多保存一張封面，且封面會在書庫列表與詳細頁顯示。
- [x] 使用者可以替換或移除既有封面。
- [x] 只接受常見圖片格式，單檔超過 5 MB 或格式不符時會顯示可理解的錯誤。
- [x] 重新載入網站後封面仍可正常顯示，不會只存在於暫時的瀏覽器狀態。
- [x] 有電腦與手機瀏覽器流程測試驗證選檔、拍照／相簿輸入、替換、移除與錯誤提示。

## Answer

- 以 SQLite BLOB 保存每本書單一封面，並保存 content type／檔名；提供封面讀取、替換與移除 API。
- 新增書籍頁提供檔案／相簿與相機輸入；詳細頁可替換或移除既有封面；書庫卡片與詳細頁顯示持久化封面。
- 前後端均驗證 JPG、PNG、GIF、WebP 與 5 MB 上限，後端另外檢查圖片 signature。
- Playwright 驗證 desktop 與 390×844 touch viewport 的選檔、相機 input、替換、移除、重新載入與錯誤提示。
- 驗證結果：Vue typecheck、Vite build、ASP.NET build 通過；封面流程 6 個、借閱／歸還流程 2 個 Playwright 測試通過。

## Comments

- 2026-09-20：MVP 只處理一張封面，不串接 ISBN 書籍資料服務，不做多圖相簿或圖片辨識。
