# 04: 借出與歸還書籍

**What to build:** 讓使用者從書籍詳細資料完成借出與歸還，並即時看到目前書籍是否在家、借給誰以及預計何時歸還。這張 ticket 建立後續借閱歷史與提醒所需的目前借閱資料。

**Blocked by:** 01: 建立書籍核心流程

**Status:** resolved

**Labels:** ready-for-agent

- [x] 只有「在家」的書籍可以執行借出操作。
- [x] 借出時借閱人為必填，借出日期由系統自動記錄為當天。
- [x] 預計歸還日期預設為借出日後 14 天，使用者可以修改或清除；備註為選填。
- [x] 借出成功後，書籍狀態變成「借出中」，詳細頁顯示借閱人、借出日期、預計歸還日期與備註。
- [x] 只有「借出中」的書籍可以執行歸還操作。
- [x] 歸還成功後，書籍狀態變回「在家」，並保留本次借閱資料供後續歷史功能使用。
- [x] 借出人未填、狀態不符或資料儲存失敗時，畫面會顯示清楚的錯誤訊息。
- [x] 有瀏覽器流程測試驗證「借出 → 顯示目前借閱資訊 → 歸還 → 狀態回到在家」。

## Answer

- 新增 `BorrowingRecord` 與 SQLite/EF Core 關聯，保存借閱人、借出日期、預計歸還日期、實際歸還日期與備註。
- 新增借出／歸還 API，限制合法狀態轉換，借閱人必填；借出日期由後端自動建立，預計歸還日預設加 14 天，也支援修改與清除。
- 詳細頁新增借出表單、目前借閱資訊與歸還操作，並顯示清楚的錯誤訊息。
- 新增瀏覽器流程與 API 邊界測試，涵蓋借出、驗證、預設／清除期限、重複狀態拒絕、歸還與狀態恢復。
