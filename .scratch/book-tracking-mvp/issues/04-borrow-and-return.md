# 04: 借出與歸還書籍

**What to build:** 讓使用者從書籍詳細資料完成借出與歸還，並即時看到目前書籍是否在家、借給誰以及預計何時歸還。這張 ticket 建立後續借閱歷史與提醒所需的目前借閱資料。

**Blocked by:** 01: 建立書籍核心流程

**Status:** ready-for-agent

**Labels:** ready-for-agent

- [ ] 只有「在家」的書籍可以執行借出操作。
- [ ] 借出時借閱人為必填，借出日期由系統自動記錄為當天。
- [ ] 預計歸還日期預設為借出日後 14 天，使用者可以修改或清除；備註為選填。
- [ ] 借出成功後，書籍狀態變成「借出中」，詳細頁顯示借閱人、借出日期、預計歸還日期與備註。
- [ ] 只有「借出中」的書籍可以執行歸還操作。
- [ ] 歸還成功後，書籍狀態變回「在家」，並保留本次借閱資料供後續歷史功能使用。
- [ ] 借出人未填、狀態不符或資料儲存失敗時，畫面會顯示清楚的錯誤訊息。
- [ ] 有瀏覽器流程測試驗證「借出 → 顯示目前借閱資訊 → 歸還 → 狀態回到在家」。
