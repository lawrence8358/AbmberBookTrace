# 06: 電腦版修改、刪除與資源回收筒

**What to build:** 讓電腦使用者能修正書籍資料並安全刪除書籍；刪除後先進入資源回收筒，30 天內可以完整還原，逾期後自動永久移除。回收流程不得破壞封面、書籍資料或借閱歷史。

**Blocked by:** 02: 書庫搜尋、篩選、排序與首頁統計；03: 書籍封面上傳與手機拍照；05: 借閱歷史與到期提醒

**Status:** ready-for-agent

**Labels:** ready-for-agent

- [ ] 電腦使用者可以修改書名、作者、ISBN、出版社、分類／標籤、位置、詳細位置、備註與封面。
- [ ] 修改後書庫列表、詳細頁、搜尋結果與首頁統計會顯示最新資料。
- [ ] 電腦使用者刪除書籍前會看到確認提示，確認後書籍進入資源回收筒。
- [ ] 進入回收筒的書籍不再出現在一般搜尋、書庫列表、首頁統計、最近新增與作者數量排序中。
- [ ] 30 天內可以還原書籍，且書籍資料、封面與借閱歷史全部恢復。
- [ ] 超過 30 天的書籍會自動永久移除，不再能被還原。
- [ ] 刪除與還原會正確更新藏書總數、在家數量、借出數量與列表排序。
- [ ] 手機介面不提供修改與刪除入口；電腦介面提供修改與刪除入口。
- [ ] 有瀏覽器流程測試驗證修改、刪除確認、回收筒、30 天內還原、逾期永久移除與統計更新。
