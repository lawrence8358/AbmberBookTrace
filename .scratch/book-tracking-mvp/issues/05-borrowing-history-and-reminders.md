# 05: 借閱歷史與到期提醒

**What to build:** 讓使用者回顧每本書過去的借閱紀錄，並在借閱到期或逾期時從網站內收到提醒。歸還不會抹除歷史，使用者可以從書籍詳細頁與借閱歷史頁理解書籍的流轉狀況。

**Blocked by:** 04: 借出與歸還書籍

**Status:** ready-for-agent

**Labels:** ready-for-agent

- [ ] 每次借出與歸還會形成一筆只讀的借閱歷史，包含借閱人、借出日期、預計歸還日期、實際歸還日期與備註。
- [ ] 書籍詳細頁可以查看該書的所有借閱歷史，並清楚區分尚未歸還與已歸還的紀錄。
- [ ] 借閱歷史頁可以瀏覽目前尚未歸還的借閱紀錄與已完成的借閱紀錄。
- [ ] 有預計歸還日期的借閱紀錄，在到期日當天顯示網站內提醒。
- [ ] 超過預計歸還日期的借閱紀錄顯示逾期通知，並能從首頁摘要或通知頁找到。
- [ ] 沒有預計歸還日期的借閱紀錄不產生到期提醒。
- [ ] 不寄送 Email、簡訊或手機推播，提醒只在網站內呈現。
- [ ] 歸還後歷史紀錄仍完整存在，且借閱歷史不可修改或刪除。
- [ ] 有瀏覽器流程測試驗證歷史保存、到期日預設 14 天、到期提醒、逾期通知與歸還後歷史呈現。

## Comments

- 2026-09-20：預計歸還日預設為借出日後兩週；使用者可以修改或清除日期。
