# 07: 手機／PC 響應式體驗與 MVP 整合驗收

**What to build:** 將前面完成的功能整合成一致的書蹤體驗，讓使用者在手機與電腦都能順暢完成核心流程，並符合溫暖、清爽、私人書房風格的視覺方向。這張 ticket 完成後，整個 MVP 可以用完整瀏覽器流程驗收。

**Blocked by:** 02: 書庫搜尋、篩選、排序與首頁統計；03: 書籍封面上傳與手機拍照；05: 借閱歷史與到期提醒；06: 電腦版修改、刪除與資源回收筒

**Status:** ready-for-agent

**Labels:** ready-for-agent

- [ ] 手機與電腦使用同一個響應式網站，主要頁面在不同螢幕尺寸下都能閱讀與操作。
- [ ] 手機版能完成搜尋、查看、新增、封面拍攝／上傳、借出、歸還、歷史與提醒流程。
- [ ] 電腦版能完成手機版全部流程，並額外顯示修改與刪除操作。
- [ ] 手機版隱藏修改與刪除入口，且不因隱藏操作而破壞詳細頁布局。
- [ ] 搜尋永遠是明顯入口；書籍位置與在家／借出中狀態在列表與詳細頁清楚可辨識。
- [ ] 使用奶油白背景、柔和綠主色、借出橘色狀態、圓角卡片與輕微陰影，且文字與狀態色保持可讀性。
- [ ] 空書庫、搜尋無結果、驗證錯誤、圖片上傳失敗、儲存失敗與找不到書籍時都有清楚的畫面提示。
- [ ] 有完整瀏覽器驗收流程驗證「新增 → 搜尋 → 查看位置 → 借出 → 查看歷史與提醒 → 歸還」，並在手機與電腦尺寸各執行一次。
- [ ] MVP 驗收確認首頁統計、封面、狀態、借閱歷史、提醒、資源回收筒與響應式操作彼此一致。
